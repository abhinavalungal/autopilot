Automatically validates and approves maritime Noon, Arrival, and Departure reports — including Bunker ROB reconciliation, duplicate detection, and compliance checks. Always loads the latest version from GitHub.

⚓ Launch Autopilot

Or copy the bookmarklet code below and create a bookmark manually.

  1. 1 Drag the Launch Autopilot button into your browser's bookmarks bar (or copy the code above into a bookmark's URL field manually).
  2. 2 Navigate to the maritime reporting web app and open the report you want to process.
  3. 3 Click the Launch Autopilot bookmark — the panel will appear in the bottom-left corner.
  4. 4 Updates are automatic. When autopilot.js is pushed to GitHub, the bookmark always fetches the newest version on next use — no reinstall needed.
